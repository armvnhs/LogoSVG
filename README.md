# 🎨 LogoSVG.ir
### A comprehensive collection of Iranian brand logos in SVG format.

**LogoSVG.ir** is a free, open-source library created to provide designers and developers with high-quality, vector-based logos of Iranian brands. No more low-quality PNGs; just clean, scalable SVG files.

[**🌐 Visit LogoSVG.ir**](https://logosvg.ir)

---

## ✨ Features
- **High Quality:** All logos are in SVG format, perfect for any screen size.
- **Easy to Search:** Find any brand instantly using the search bar.
- **Open Source:** This project belongs to the community and grows with your help.
- **Fast & Light:** Built to be quick and easy to use on both desktop and mobile.

---

## 📂 Project Structure
- **/logos**: This folder contains all the official SVG files.
- **logos.json**: A simple database used to display names and categories on the website.
- **index.html**: The main website interface.

---

## 🤝 How to Help
We want to collect every Iranian logo! You can contribute in two ways:
1. **Through the Website:** Click on the **"Send Logo" (ارسال لوگو)** button.
2. **On GitHub:** Simply upload the `.svg` file to the `logos` folder and send a Pull Request.
